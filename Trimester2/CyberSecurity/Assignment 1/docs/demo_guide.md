# Demo Guide

Use the following steps to demonstrate the project for assessment purposes.

1. Start the app:
   - Run `python app.py`
   - Open http://127.0.0.1:5000/
2. Register a new user account.
3. Log in with the new account.
4. Add an asset such as a payroll database or customer records system.
5. Record a risk such as credential stuffing or phishing.
6. Observe the suspicious-activity messaging and the risk display on the dashboard.
7. Capture screenshots of the landing page, dashboard, and risk entry flow.

These steps provide a clear demonstration of authentication, asset management, risk handling, and security monitoring.
